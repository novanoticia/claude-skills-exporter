# Política de seguridad

## Versiones con soporte

El mantenimiento de seguridad se centra en la última versión publicada del proyecto.

Si utilizas una versión anterior, actualiza a la más reciente antes de comprobar si el problema sigue presente.

## Cómo comunicar una vulnerabilidad

Si detectas una posible vulnerabilidad, comunícala de forma privada a:

novanoticia@icloud.com

No abras una incidencia pública con instrucciones de explotación, credenciales, datos personales ni información que pueda poner en riesgo a otras personas.

Incluye, cuando sea posible:

- Una descripción del problema y de su posible impacto.
- La versión del proyecto o el identificador del commit afectado.
- Los pasos necesarios para reproducirlo.
- El navegador, sistema operativo y demás detalles relevantes.
- Una prueba de concepto mínima, sin datos personales ni secretos.

## Revisión y corrección

Este proyecto se mantiene con recursos limitados. Los informes se revisarán según la disponibilidad de mantenimiento y la gravedad del problema.

No se garantiza un plazo concreto de respuesta o resolución.

Si se confirma una vulnerabilidad, se valorará una corrección y la publicación de la información necesaria para que las personas usuarias puedan protegerse.

Agradecemos que no se divulguen los detalles técnicos hasta que se haya podido valorar el problema y coordinar su publicación.

## Investigación responsable

Realiza las pruebas únicamente con cuentas, datos y sistemas propios, o con autorización expresa.

No accedas a información de otras personas, no interrumpas servicios y no publiques credenciales ni datos sensibles.

## Reconocimientos

Con el consentimiento de quien haya informado del problema, se podrá reconocer su contribución.

Este proyecto no ofrece un programa de recompensas económicas.
