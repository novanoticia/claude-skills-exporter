1 · La idea en 60 segundos

Un plugin de Claude es una caja con cinco cosas dentro. Sólo una de ellas se puede llevar a otra plataforma:

Qué hay dentro¿Viaja?Por qué
skills/✅ SíEs el estándar abierto Agent Skills, que ChatGPT, claude.ai, Perplexity y Mistral también entienden — y que Claude Code sigue leyendo
commands/❌ NoLos comandos /algo son propios de Claude Code
agents/❌ NoNo existen los subagentes en el destino
Servidores MCP❌ NoEl destino no tendrá esas conexiones
hooks/❌ NoAutomatismos internos de Claude
Expectativa realista Esto no es un botón mágico de «convertir plugin». Extrae las skills, arregla lo que se puede arreglar solo, y te avisa por escrito de lo que no: el informe abre con una matriz que dice, destino a destino, si la skill queda compatible, compatible con adaptaciones, degradada, no verificable o no compatible. Una skill que llamaba a una base de datos por MCP seguirá siendo un buen procedimiento escrito, pero no podrá consultar esa base de datos.

2 · Poner esta herramienta en tu ordenador

Sólo necesitas Python 3 (versión 3.8 o posterior; ya viene en macOS y Linux). git hace falta únicamente si vas a convertir desde una URL de GitHub: con una carpeta que ya tengas descargada no se usa. Comprueba que los tienes abriendo la Terminal y escribiendo:

python3 --version && git --version

Si ambos responden con un número de versión, ya está. Ahora descarga esta herramienta:

A Opción sin terminal

En la página del repositorio en GitHub, pulsa el botón verde Code → Download ZIP. Descomprime el archivo donde quieras, por ejemplo en tu carpeta de Descargas.

B Opción con terminal

cd ~/Descargas
git clone https://github.com/novanoticia/claude-skills-exporter.git
cd claude-skills-exporter

Esto requiere que el plugin esté instalado. Si mantienes tu propia copia del repositorio, la publicación y la instalación desde el marketplace están en la guía de mantenimiento.

3 · Convertir un repositorio

Un solo comando. Abre la Terminal, sitúate en la carpeta de la herramienta y escribe:

python3 skills/plugin-to-agentskills/scripts/convert.py \
    https://github.com/USUARIO/REPO-CON-EL-PLUGIN \
    --out ./salida
Truco: no escribas la ruta a mano En macOS, escribe python3 (con el espacio final) y luego arrastra el fichero convert.py desde el Finder hasta la ventana de la Terminal. La ruta se escribe sola.

También funciona con una carpeta que ya tengas descargada:

python3 skills/plugin-to-agentskills/scripts/convert.py ~/Descargas/mi-plugin --out ./salida

Ese comando es la forma corta de export. Hay dos más, que no escriben nada en disco: inspect (qué contiene y qué exige cada skill, sin elegir destino) y audit (sólo la matriz de compatibilidad, con --target para mirar un destino concreto).

Qué aparece en la carpeta salida/

Cada skill sale en dos formas, y no son intercambiables. El .zip sirve para Perplexity, ChatGPT y claude.ai; la carpeta, para Mistral y Claude Code. Llevan los mismos ficheros, pero la descripción se ajusta al espacio que admite cada plataforma: hasta 850 bytes en el zip, hasta 490 en la carpeta. Por eso descomprimir el zip no vale para Mistral: la descripción que sale es la larga.
Carpeta o ficheroPara qué sirve
mi-skill.zipPara Perplexity, ChatGPT y claude.ai. Se sube sin tocarlo
mi-skill/Para Mistral y Claude Code. La carpeta, no el zip abierto
INFORME-PORTABILIDAD.mdLéelo. Abre con una matriz que dice, destino a destino, si la skill es compatible, compatible con adaptaciones, degradada, no verificable o no compatible; luego detalla por skill qué se adaptó solo y qué la bloquea en cada plataforma
resumen.jsonEl informe en formato máquina y, además, la lista de hallazgos con el fichero y la línea exactos, que el informe en Markdown no incluye

Habrá un .zip y una carpeta por cada skill del repositorio original.

Lee el informe antes de subir nada En la matriz, 🔴 no marca la skill entera: marca una casilla, es decir «no compatible con ese destino concreto». La misma skill puede salir 🔴 en Mistral y 🟢 en Claude Code. Mira la columna del destino al que vayas a subirla. Un 🔴 puede venir de una capacidad que el destino no tiene (MCP, subagentes, ejecutar scripts) o de un peligro de conducta observado, no sólo de una instrucción que vaya a fallar. Puedes subirlas igualmente —llevan un aviso incrustado para que el agente lo declare en vez de fingir— pero conviene saberlo de antemano.
Y un 🟡 casi nunca falta En cuanto la herramienta toca algo de la skill —reordenar la descripción, retirar una clave de frontmatter que sólo existe en Claude— todas las columnas de esa fila suben a 🟡 «adaptación», incluida la de Claude Code. No es un aviso de que algo vaya mal en el destino: es un aviso de que lo que vas a subir ya no es exactamente el fichero original. 🟢 puro significa que no se tocó nada.

4 · Lo que la herramienta mira además de la portabilidad

Al convertir un repositorio, la herramienta responde a dos preguntas distintas, y conviene no confundirlas. La primera es «¿dónde puedo subir esto?», que es lo que has venido a hacer. La segunda es «¿debería instalar esto?», que casi nadie se plantea, y por eso el informe la contesta arriba del todo sin que la pidas.

Para contestarla lee el repositorio entero —no sólo las skills— buscando cosas que un paquete honrado no necesita hacer: descargar algo de internet y ejecutarlo sin mirarlo, dejar instalada una tarea que siga corriendo después, leer contraseñas del sistema, borrar el rastro de lo que ha hecho, o traer instrucciones escondidas para que el agente actúe a espaldas de quien lo usa.

No ejecuta nada, sólo lee Ni instala, ni descomprime, ni lanza ningún programa del repositorio. Sólo lee ficheros y busca formas conocidas. Eso tiene una consecuencia honesta: encuentra lo que se parece a algo que ya conoce, y no puede afirmar que un repositorio sea inofensivo. Sólo puede decirte dónde mirar.

El nivel de riesgo

El informe empieza con una sola palabra que resume todo lo encontrado:

NivelQué significa
🟢 bajoNo se ha encontrado nada reseñable. Instalación razonable después de leer el informe
🟡 moderadoHay cosas que conviene mirar antes de instalar, pero ninguna grave
🟠 altoHay algo que no encaja con un paquete que sólo pide lo que necesita. No lo instales sin que alguien lo revise
🔴 críticoHay indicios serios, o varios problemas graves que se refuerzan entre sí. No se puede recomendar la instalación
🔵 no evaluableHay material que no se ha podido leer —un fichero comprimido, un binario sin explicación, un fichero sin permisos—. No es que esté mal: es que no se sabe
«No evaluable» no es un aprobado Es lo contrario de un veredicto. Significa que parte del paquete quedó fuera del análisis, así que lo que el informe diga sólo vale para el resto. Si lo que no se pudo leer te importa, ábrelo tú.

Por qué el mismo problema a veces sólo avisa y a veces te frena

Es la idea más importante de todo esto y se entiende con una pregunta: ¿ese fichero viaja dentro de lo que vas a subir, o se queda en el repositorio?

Dónde estáQué pasa
Dentro de la carpeta de una skillVa a acabar en el .zip que subes a otra plataforma. Si el hallazgo es grave, la herramienta no escribe esa skill
En cualquier otro sitio del repositorioNo viaja contigo. Sale en el informe como aviso, y los artefactos sí se escriben

Por eso el mismo fichero problemático puede ser un simple aviso o un frenazo, según en qué carpeta esté. No es una incoherencia: es que sólo una de las dos copias acaba en manos de la plataforma a la que subes la skill. Un instalador dudoso en la raíz del repositorio es asunto de quien clone ese repositorio; el mismo instalador dentro de la skill pasa a ser asunto tuyo, porque lo estás subiendo tú con tu nombre.

Y el frenazo es por skill: si tienes cinco skills y una está señalada, las otras cuatro se exportan con normalidad.

Si la terminal termina con «3»

Ese número significa exactamente una cosa: había un hallazgo grave dentro de lo que se iba a empaquetar, así que esa skill no se ha escrito. No es que la herramienta se haya roto.

Qué hacer, en este orden
  1. Abre INFORME-PORTABILIDAD.md y busca el bloque de arriba. Te da el fichero y la línea exactos.
  2. Abre ese fichero por esa línea y míralo. En un minuto sabrás si es un problema real o un ejemplo que el autor documentaba a propósito.
  3. Si es un problema real, no lo subas. Avisa a quien mantiene el repositorio.
  4. Si es un falso positivo, ya sabes por qué, y puedes decidir con criterio.
Existe una opción para saltárselo. No empieces por ahí. --anular-revision-seguridad exporta igualmente y deja constancia escrita en el informe. Está pensada para cuando ya has mirado el hallazgo y sabes que es un falso positivo —una skill que documenta un ataque, por ejemplo, en vez de cometerlo—. Usarla sin haber leído el hallazgo convierte la comprobación en un trámite, y entonces deja de servir para nada el día que el aviso sea de verdad.

5 · Subir a Perplexity Computer

1 Abre la página de skills

Ve a perplexity.ai/computer/skills.

2 Crea la skill

Arriba a la derecha: + Create skill → Upload a skill.

3 Arrastra el zip

Coge un fichero .zip de la carpeta salida/ y suéltalo en la ventana, sin descomprimirlo ni modificarlo. Repite para cada skill que quieras instalar.

4 Compruébalo

Abre un chat nuevo y pide algo que encaje con la descripción de la skill. Si no se activa, el problema casi siempre es la descripción — ver sección 7.

Un zip, una skill Perplexity espera encontrar la carpeta de una sola skill en la raíz del zip. Por eso la herramienta genera un zip por skill y nunca uno con todas dentro. Si comprimes varias juntas por tu cuenta, lo normal es que falle o sólo reconozca una.

6 · Subir a Mistral (Vibe Work)

Son los mismos ficheros que acabas de subir a Perplexity, pero no el mismo artefacto: Mistral quiere la carpeta que dejó la herramienta —con la descripción recortada a 490 bytes—, no el zip descomprimido.

1 Abre el panel de skills

chat.mistral.ai/work → pestaña Work → barra lateral izquierda → Context → Skills → New Skill.

2 Localiza la carpeta de la skill

En salida/, junto a cada .zip, hay una carpeta con el mismo nombre y sin la extensión: mi-skill.zip → mi-skill/. Sube esa carpeta.

No descomprimas el zip para esto. La carpeta y el zip no son iguales: llevan los mismos ficheros, pero la descripción de la carpeta está recortada a 490 bytes, que es lo que admite Mistral. Si sólo conservaste el .zip, vuelve a ejecutar el conversor en vez de abrirlo.

3 Súbela

Entrega la carpeta con todo su contenido — SKILL.md y, si los hay, los ficheros de references/ y scripts/. Si la skill original tenía enlaces simbólicos no estarán: la herramienta los omite a propósito —copiarlos habría metido en el paquete un fichero de fuera de la skill— y lo avisa en el informe. Mistral mantiene las subcarpetas tal cual y acepta cualquier extensión, no sólo markdown: los .py y .yaml viajan igual. Pero viajar no es ejecutarse: Mistral no tiene Python, así que una skill cuya lógica viva en scripts/ sale marcada como no compatible con este destino, y el SKILL.md debe traer un procedimiento manual equivalente.

El contenido de SKILL.md pasa a ser el panel Instrucciones de la skill.

4 Crear y probar

Create Skill, y lanza una tarea que encaje con la descripción. Si te sirve al resto del equipo, pulsa Publish.

A Mistral no le subas el .zip Y al revés: a Perplexity no le subas la carpeta. Es el mismo contenido, pero cada plataforma lo quiere en su envoltorio.

7 · Si algo falla

SíntomaCausa habitualQué hacer
No se encontró ningún SKILL.md El repo es un plugin de sólo comandos o sólo MCP No hay nada portable. Es el resultado correcto, no un error
Perplexity rechaza el zip El zip lleva varias skills dentro, o lo recomprimiste tú y quedó un nivel de carpeta de más Sube uno de los .zip que generó la herramienta, sin modificarlo
Perplexity dice «description exceeds maximum length of 1024 characters» La descripción se pasa del límite, que se mide en bytes: en español las tildes cuentan doble Vuelve a exportar con la versión actual de la herramienta, que ajusta la descripción al presupuesto de cada destino
Mistral no acepta el archivo Le estás subiendo el .zip Sube la carpeta que dejó la herramienta al lado del zip. Descomprimir el zip no vale: su descripción es la larga
Mistral dice «sube un archivo Markdown válido de skill» El markdown que le diste habla de una skill en vez de ser una skill: le falta el frontmatter Sube el SKILL.md que hay dentro de la carpeta, no un documento intermedio
La skill se instala pero nunca se activa La descripción dice qué hace en vez de cuándo usarla Reescríbela empezando por «Cárgala cuando el usuario…» y con las palabras que tú usarías al pedirlo
Se activa cuando no debe Descripción demasiado genérica Añade qué no cubre: «No la uses para X»
El agente dice que ejecutó algo que no existe La skill llamaba a una herramienta MCP El informe te dice en qué destinos sale 🔴 y por qué («mcp.cliente: requerida por la skill…»), pero no en qué línea. Para eso mira resumen.json o las «Notas de portabilidad» que la herramienta añade al final del SKILL.md exportado. Reescribe ese paso como instrucción neutral
En Perplexity, un proceso largo se queda a medias Corta cada llamada en torno a 90 segundos Pídele que trabaje en lotes pequeños y que verifique el resultado después de cada uno
git: command not found Falta git macOS: escribe git en la Terminal y acepta instalar las herramientas de desarrollo. Windows: git-scm.com
install dice que no existe el plugin Confundir el nombre del marketplace con el usuario de GitHub Después de la arroba va pablo-skills-tools, que es el campo name de marketplace.json
Instala pero los comandos no aparecen Falta recargar /reload-plugins, y comprueba con /plugin que está en la lista y activado

La regla de oro de las descripciones

El 80% de los problemas de una skill importada están en una línea. El destino no lee el cuerpo para decidir si carga la skill: lee sólo la descripción, y la paga en tokens en cada sesión.

❌ Mal✅ Bien
«Esta skill genera informes financieros.» «Cárgala cuando el usuario pida un informe financiero, un cierre mensual o una comparativa presupuesto-real.»
«Ayuda con reuniones.» «Cárgala cuando el usuario pegue notas o una transcripción de reunión y pida un resumen o los acuerdos.»

Nota ética. Esta guía y la herramienta que documenta se han elaborado con asistencia de IA. Requieren revisión humana antes de usarse en producción. Las rutas de interfaz de los cinco destinos (ChatGPT, claude.ai, Claude Code, Mistral Vibe Work y Perplexity Computer) pueden cambiar sin previo aviso: si no encuentras un botón donde dice aquí, consulta la documentación oficial de cada plataforma.
